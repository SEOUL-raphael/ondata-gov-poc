원본과 웹 구현

원본 85쪽 매뉴얼과 소스 ZIP의 tobeO.py, CommFunF.py, RandomForest/RF_regression_Discrim.py, tobemap_geo.py를 확인했습니다. 실행파일에 포함된 외부 라이브러리는 모델 자체 소스로 취급하지 않습니다.

원본은 공공자전거·그늘막·전기차충전소·택배함·이동노동자쉼터의 100m 격자 환경변수와 설치여부를 학습한 Random Forest입니다. 미설치 격자의 분류 확률 상위 N개를 3등급으로 추천합니다. 확률은 기존 설치 패턴 유사성이며 이용 수요나 정책효과 확률이 아닙니다.

  • 원본 시설별 변수 목록을 그대로 검증하고 결측을 임의로 0으로 바꾸지 않습니다.
  • 고유 격자 50/50 층화 분할 후 학습집합만 소수 계층 증강하여 원본의 검증 누수 위험을 수정했습니다. 100트리, seed42. 원본과 동일한 AUC·추천을 보장하지 않습니다.
  • ROC·AUC·혼동행렬·변수 중요도, 후보 표, 지도 확대/이동/순위 표시 전환, CSV·JSON·독립 HTML 저장을 제공합니다.
  • GeoJSON 격자+점 레이어 전처리 패키지로 PROJ 변환과 Shapely within 결합, 개수·합계·평균·고유값·설치여부 집계를 수행합니다.
  • 전체 원시 SHP/XLSX 폴더 자동 ETL·지오코딩·업종 개편 매핑, 연구 당시 5개 알고리즘 비교실험, 도로/행정경계 배경지도·마커 편집은 미구현입니다. 원본 변수의 집계 의미와 실제 격자 규격에 맞게 입력을 준비해야 합니다.

입력 역할과 흐름

분석 선택 → 예제/데이터 카드/파일 → 역할·컬럼·좌표·범위 확인 → 조건 설정 → 계산 → 지도·표·커버리지 → 다운로드 순서입니다. 역할별 CSV 템플릿을 화면에서 내려받을 수 있습니다.

JSON 입력은 {metadata:{...},rows:[...]}입니다. metadata에는 source, region, period, crs, kind, semantic_id가 필요합니다. kind는 synthetic/snapshot/live/user-file이며 역할 간 지역·시점·좌표계·종류가 다르면 차단합니다. 지역 이름의 일치가 실제 행정경계나 자료 정확성을 입증하지는 않습니다.

  • RF mart: siting-mart-v1, id/x/y와 선택 시설별 필수 설명변수·설치여부0/1, grid_size_m=100. 각 계층 최소4개.
  • demand: demand-points-v1, id/x/y/weight 및 weight_unit. 가중치는0 이상.
  • candidates: candidate-sites-v1, id/x/y. 설치 가능성은 사전 조사로 확인합니다.
  • existing: facility-points-v1, id/x/y. 기존 시설 없음은 rows:[]를 명시합니다.

EPSG:4326은 x=경도,y=위도, 반경6,371,008.8m 구면 Haversine 거리입니다. EPSG:5179/5186은 m 단위 유클리드 거리입니다. LOCAL_METRE는 합성 전용입니다. 좌표계 선택은 변환이 아니며 전처리에서 PROJ로 변환합니다. 경위도 지도 화면은 거리 축척이 아닙니다.

수요 커버리지 확장

원본 RF와 별개로 기존 시설을 고정하고 신규 N개, 반경, 최소이격, 목표 커버리지 조건에서 중복 없는 수요 가중치 합을 최대화합니다. 완전탐색은100,000조합 및 조합×수요20,000,000 이하, 거리쌍4,000,000 이하에서 전역 최적을 구합니다. 탐욕은 매 단계 추가 수요가 최대인 후보를 선택하며 전역 최적을 보장하지 않습니다. 탐욕 실패는 모든 조합이 불가능하다는 증명이 아닙니다.

RF의 인구 설명변수 하나를 명시하면 고정된 추천의 기존/추가 후 커버리지를 비교할 수도 있습니다. 도로망·이동시간·용량·예산·인허가는 계산하지 않습니다. 입력/조건 변경 시 이전 결과를 지우며 부족한 입력·불가능한 제약·시간 초과를 성공으로 표시하지 않습니다.

합성 예제와 공식 시점 자료

RF80격자, 커버리지 정답, 공간 집계 예제는 모두 합성입니다. 정답 사례는 총100, 기존30, C2 추가 후100입니다. 원본 기관 데이터는 재배포 권리 미확인으로 포함하지 않았습니다.

서울시 공식 대여소 파일의 2026년6월 자료(2026-07-15 게시)를 2026-09-09 확보하고 2,789개 위치로 정규화했습니다. 공공누리1 출처표시 조건으로 출처·원본 해시 포함 JSON을 제공합니다. 공식 XLSX 응답에 CORS 허용 헤더가 없어 자체 시점 파일을 사용합니다. 기존 따릉이 실시간5개소 표본과 다릅니다. 위치 자료는 주민 수요나 설치 가능한 후보지로 자동 간주하지 않습니다.

재사용 데이터 카드4종에는 서울 대여소, 국토통계 격자, 상가 업소, 전기차 충전소의 출처·스키마·연결 조건이 있습니다. 서울 자료 외에는 전체 자동 수집을 검증하지 않았습니다. 파일별 이용조건·키·SHP PRJ·업종 의미를 확인하세요. 업소/격자는 전처리 재료이며 완성 RF 마트가 아닙니다.

AI와 실행 환경

수치는 브라우저 Worker 코드로 계산합니다. 동의한 계산 사실과 해시만 기존 AI로 보내며 좌표·원본 파일은 보내지 않습니다. 원문 인용 일치 검사는 의미 정확성 보장이 아닙니다. 로컬 서버는 기존 로컬 LLM 설정을 우선 사용하나 현재 기본 모델이 미설정이라 로컬 실호출 검증은 하지 못했습니다.
