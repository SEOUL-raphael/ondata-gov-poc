표준분석모델 웹 예제

정보공개청구: 기존 공개용 합성 예제 4,000건 재사용.
민원: 매뉴얼 대시보드용 12종 합성 본문과 가상 지역·배정일·기한을 포함한 120건.
각 모델의 CSV와 XLSX는 같은 값을 포함합니다. 엑셀 시트 이름은 분석데이터입니다.
웹 화면에서 해당 모델을 선택하고 파일을 업로드한 뒤 통계 분석을 실행하세요.
실제 기관 데이터가 아니며 분석 품질·정책 결론을 입증하지 않습니다. 민원 본문은 반복되며 좌표와 인구는 가상입니다.
출처·변환·파일 해시는 standard-model-examples.json을 참고하세요.
